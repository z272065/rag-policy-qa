# 数据分级与保密

## 数据分级

公司的数据分为公开、内部、机密、绝密四级。公开数据是已经对外发布的信息，如官网内容和公开的产品介绍。内部数据是日常工作中产生的、仅限员工使用的信息，如会议纪要和内部通知。机密数据是泄露后会对公司或客户造成明显损失的信息，如客户名单、报价、源代码和未发布的产品方案。绝密数据是泄露后会造成严重后果的信息，如核心算法、并购计划和重大合同的未公开条款。

数据的定级由数据产生部门的负责人负责，新产生的数据在创建时即须标注级别。未标注级别的数据，按内部级别处理。对数据级别有疑问的，向 IT 部门咨询，IT 部门在 2 个工作日内给出建议。

数据级别可以调整。数据内容变化或保密期限届满的，数据负责人提出调整申请，机密及以上级别的降级须由部门负责人审批。降级后，原访问记录保留不变。

数据的级别决定了谁能访问、能否外发以及保存多久。机密数据的保存期限不少于 3 年，绝密数据不少于 5 年，期限届满前不得删除，确需提前删除的，须经部门负责人和 IT 部门共同确认。

同一份资料同时含有多个级别的数据的，按其中最高的级别处理。数据级别须在文件名或文档页眉中标明，机密及以上的电子文件须加水印，水印包含查看人的姓名和查看时间，便于泄露后追溯来源。员工发现他人的数据级别标注明显错误的，可向 IT 部门反馈。

## 外发审批

机密级别的数据需要发给公司以外的人员时，须在钉钉提交外发申请，写明数据内容、接收方、用途和发送方式，由部门负责人审批。绝密数据的外发还须总经理审批。内部级别的数据发给外部的，须由发送人确认接收方与公司有保密约定，无约定的不得发送。

## 保密承诺

员工在入职时签署保密承诺书，承诺在任职期间和离职后继续保守公司的商业秘密和客户信息，不得对外披露，也不得用于本职工作以外的目的。保密义务不因离职而终止，离职时员工须再次签署离职保密确认。

## 客户数据处理

处理客户数据须遵循最小必要原则，只访问完成工作所需的数据，不得拷贝全量数据。开发和测试环境使用客户数据前，须对手机号、证件号、地址等个人信息脱敏。对客户数据的每次访问系统自动留痕，访问记录保存 180 天，IT 部门每月抽查异常访问。

## 备份与销毁

机密及以上数据每日做增量备份，每周做全量备份，备份文件加密后存放在异地的存储中。备份的恢复演练每半年进行 1 次，由 IT 部门负责，演练结果报部门负责人。

备份文件的保存期限与原数据相同，期限届满后须销毁。纸质资料由两名员工共同监销，使用碎纸机粉碎并签字确认。电子数据使用专用工具擦除，擦除后由 IT 部门出具记录。含机密数据的存储介质报废的，须物理销毁，并留存销毁记录 3 年。

临时存放机密数据的文件、截图和聊天记录，须在使用完毕后 7 日内清理。员工不得保留工作数据的私人备份，离职时由 IT 部门核查。

销毁须经数据负责人确认，未经确认的数据不得销毁。销毁记录由 IT 部门保存，包括数据名称、级别、销毁日期、方式和监销人。销毁记录每年由 IT 部门汇总一次，报部门负责人备案。

备份和销毁的执行情况由 IT 部门每季度向部门负责人通报，通报内容包括备份成功率、恢复演练结果和待销毁的数据清单。备份失败的，IT 部门须在 24 小时内重做并查明原因，未按期备份的系统，IT 部门通知系统负责人限期整改。

## 泄露事件处置

发现或怀疑数据泄露的，员工须在 1 小时内报告 IT 部门和直属主管，IT 部门立即采取措施，如停用相关账号、撤回外发邮件和隔离受影响的系统。IT 部门在 24 小时内出具初步报告，写明泄露的数据范围、可能原因和已采取的措施。涉及客户个人信息的泄露，由法务评估是否需要通知客户和监管部门，需要通知的，在法定时限内完成。
